                                             Abstract. The length function ℓ2 (r, R) is the smallest length of a binary linear code
                                         with codimension (redundancy) r and covering radius R. Let s2 (N, ρ) be the smallest size
                                         of a ρ-saturating set in the projective space PG(N, 2). It is known that ℓ2 (r, R) = s2 (r −
                                         1, R − 1). We obtain the following new upper bounds on ℓ2 (r, 2), which yield a decrease
                                         ∆(r, 2) compared to the best previously known upper bounds: r = 2t, r = 10, 18, 20 and
                                         r ≥ 28, ℓ2 (r, 2) = s2 (r − 1, 1) ≤ 51 · 2r/2−5 − 1; ∆(r, 2) = 2r/2−5 . To obtain these bounds,
                                         we construct a new infinite code family, using distinct versions of the q m -concatenating
                                         constructions of covering codes; some of these versions are proposed in this paper. We also
                                         obtain new useful partitions of column sets of parity check matrices of some codes. The
                                         asymptotic covering density µ(2) ≤ 1.27002, provided by the codes of the new family, is
                                         smaller than previously known one and gives rise to the new upper bound f (2) ≤ 1.27002
                                         on the constant f (2) of the Green’s Open Problem 40.
                                             Keywords: Binary covering codes, the length function, covering radius

Definition 1.1. A binary linear [n, k]2 code C has covering radius R if any of the following
equivalent conditions holds:
   (i) The value R is the smallest integer such that the space Fn2 is covered by binary
Hamming balls of radius R centered at all the codewords of C.
   (ii) Every vector in Fn−k

Definition 1.4. The length function ℓ2 (r, R) is the smallest length of a binary linear code

    The study of covering codes is a classical combinatorial problem. Covering codes are
connected to many areas of information theory, combinatorics, and practical applications,
see [7, Section 1.2], [16, Section 1.2], [17, Section 1.2], and the references therein.
    For an introduction to coverings of vector Hamming spaces over finite fields, see [3,
7, 15, 20, 26, 32] and the references therein. The results and problems, related to covering
codes, are discussed in numerous works; for example, see the online bibliography [36], the
papers [1, 5, 6, 8, 11–14, 16–19, 21, 24, 31, 33–35, 39, 41, 42] and [27, Section 5, Problem 40].
    Let PG(N, 2) be the binary N -dimensional projective space over F2 . A point set
S ⊆ PG(N, 2) is ρ-saturating if every point of PG(N, 2) can be written as a sum of at
most ρ + 1 points of S and ρ is the smallest value with this property. Saturating sets
are also called “saturated sets”, “spanning sets”, and “dense sets”. A ρ-saturating set is
called minimal if one cannot remove any point from the set without losing the ρ-saturating
property.
    Let s2 (N, ρ) be the smallest size of a ρ-saturating set in PG(N, 2). If the positions of
a column of a parity check matrix of an [n, n − r]2 R code are interpreted as coordinates
of a point in PG(r − 1, 2), then this matrix corresponds to an (R − 1)-saturating n-set
in PG(r − 1, 2), and vice versa. Thus, there is a one-to-one correspondence between
[n, n − r]2 R codes and (R − 1)-saturating n-sets in PG(r − 1, 2). This implies

                                 ℓ2 (r, R) = s2 (r − 1, R − 1).                            (1.3)

Note also that a minimal ρ-saturating set corresponds to a locally optimal covering code.

     Green’s Open Problem 40. [27, Section 5, Problem 40] Let R be a fixed positive
integer. Let f (R) be the smallest constant with the following property: there exists an
infinite sequence of integers n together with subspaces Vn ⊆ Fn2 such that the space Fn2
is covered by binary Hamming balls of radius R centered at all the vectors of Vn and
#Vn = (f (R) + o(1))2n /VR,n,2 . Does f (R) → ∞?
     By above, see (1.1) and (1.2), the Green’s Open Problem 40 is connected with finding
infinite families of binary codes with relatively small asymptotic covering density; one
can put f (R) = lim inf r→∞ µ(n = ℓ2 (r, R), R); therefore an infinite code family providing
µ(R) ≤ c, where c is a constant, gives rise to estimate f (R) ≤ c.
     In [27], it is noted that f (1) = 1 (due to the Hamming codes) and the best-known
upper bound on f (2) (at the time of writing [27] 2013-2018) is f (2) ≤ 1.4238 (with refer
to [8]). Here there is a small inaccuracy in the reference: in fact, the value 1.4238 was
represented in the conference ACCT-3 in 1992, see [12, p. 53], and then have published
in [13, Example 3.1, equation (1.3)] in 1994. At that, both the papers [12, 13] use the
methods proposed in [8]. Note also that in [16, equation (2.1), Theorem 5.7] at November
2025, the upper bound was improved to f (2) ≤ 1.32031.
     This paper is devoted to new constructive upper bounds on the binary length functions
ℓ2 (r, 2). If there is an [n, n − r]2 2 code, then ℓ2 (r, 2) ≤ n. For q = 2, R = 2, we
consider the known versions of the q m -concatenating constructions of covering codes, see
e.g. [8, 13, 15–19], and propose new ones. To use the constructions effectively, we obtain
new useful partitions of column sets of parity check matrices for certain covering codes.
As a result, we obtain new infinite family of covering codes that provides improved upper
bounds on ℓ2 (r, 2) and smaller asymptotic covering densities µ(2) (1.2) compared with
previously known values; this implies the improvement of the upper bound on the constant
of the Green’s Open Problem 40 to f (2) ≤ 1.27002. Also, we obtain a few sporadic new
covering codes, see Section 2 for details.
     The new [50, 40, 3]2 2 code and the partition of column set of its parity check matrix
into 10 subsets, proposed by Stephen Wu, see [43], play a very important role in obtaining
new results. In particular, the code is used as a seed in the q m -concatenating constructions
for q = 2, R = 2.
     The paper is organized as follows. In Section 2, we collect the new results and compare
them with the known ones. In Section 3, we give a description of a basic q m -concatenating
construction for q = 2. In Section 4, we describe the known results, useful for this paper.
In Section 5, we obtain the new results.

3     Basic q m-concatenating Construction QM for q = 2
Throughout this paper, all matrices and columns are binary. An element of F2m written in
a binary matrix denotes an m-dimensional binary column, that is a binary representation
of this element; and vice versa, an m-dimensional binary column can be viewed as an
element of F2m .

Definition 3.1. [13, Definition 2.1], [15, Definition 2.1] Let H ∈ F2r×n be a parity check
r × n matrix of an [n, n − r]2 R code C and let 0 ≤ ℓ ≤ R.

(i) A partition of the column set of the matrix H into nonempty subsets is called an
     (R, ℓ)-partition if every column of F2r (including the zero column) is equal to a sum
     of at least ℓ and at most R columns of H belonging to distinct subsets. For an
     (R, 0)-partition we can formally treat the zero column as the sum of 0 columns. We
     use the term “R-partition” when the value of ℓ is not relevant or not known.

(ii) If H admits an (R, ℓ)-partition, the code C is called an (R, ℓ)-object of the space F2n
      and is denoted as an [n, n−r]2 R, ℓ or an [n, n−r, d]2 R, ℓ code. It is not necessary that
      ℓ is the greatest value with the properties considered. Therefore, any (R, ℓ)-partition
      with ℓ ≥ 1 is also an (R, ℓ1 )-partition with ℓ1 = 0, 1, . . . , ℓ − 1. So, an [n, n − r]2 R, ℓ
      code with ℓ ≥ 1 is also an [n, n − r]2 R, ℓ1 code with ℓ1 = 0, 1, . . . , ℓ − 1.

    As will be shown later in the paper, using (R, ℓ)-objects with ℓ ≥ 1 allows us to
improve parameters of new codes obtained by the q m -concatenating constructions.
    Let p(H, ℓ; P) be the number of subsets in an (R, ℓ)-partition P of a parity check
matrix H of an [n, n − r]2 R, ℓ code. Obviously, R ≤ p(H, ℓ; P) ≤ n. If p(H, ℓ; P) = n,
i.e. every subset contains one column, then the partition P is called trivial. The trivial
partition of a parity check matrix of an [n, n − r]2 R, ℓ code is an (R, ℓ)-partition. We use
the notation p(H, ℓ) when the partition P is not relevant. In other words, the notation
p(H, ℓ) means that the matrix H admits an (R, ℓ)-partition into p(H, ℓ) subsets. For
the notations p(H, ℓ; P) and p(H, ℓ), the value of R is defined by the context.

Lemma 3.2. [8,9,13], [15, Lemma 2.2] An [n, n − r, d]2 R code is an [n, n − r, d]2 R, ℓ code
with ℓ ≥ 1 if and only if d ≤ R. If d > R the maximum possible value of ℓ is zero.

   Throughout the paper, all examined codes have minimum distance d ≥ 3. So, all
codes of covering radius R = 2 are (2, 0)-objects. Therefore, for codes of covering radius
R = 2, for short, we use the notations [n, n − r]2 2 and [n, n − r, d]2 2 codes, 2-objects,
2-partition, p(H; P), p(H).
   The q m -concatenating constructions were proposed in 1990 in [8] and then investigated
and developed in numerous works, see e.g. [3, 9, 11–19, 24], [7, Section 5.4], [41, Supple-
ment], and the references therein. The term “q m -concatenating constructions” is not

     Starting from an [n0 , n0 − r0 ]q R code of length n0 , the q m -concatenating constructions
yield new [n, n − (r0 + Rm)]q R codes with the same covering radius R and length n =
q m n0 + Nm , where m must satisfy some conditions and Nm ≤ Rθm,q , with θm,q = (q m −
1)/(q − 1), θm,2 = 2m − 1. The covering density of the new codes is almost the same
(slightly greater) as for the starting code. Using the constructions iteratively, we can
obtain infinite families of new [n, n − (r0 + Rm)]q R codes where m ranges over an infinite
set of integers.
